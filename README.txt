ABRIR administrar.html PARA EDITAR NOVEDADES

El editor guarda borradores en el navegador local.
Para publicar cambios:
1) Abrir administrar.html.
2) Crear o editar noticias.
3) Presionar "Descargar contenido.js para publicar".
4) Reemplazar contenido.js en la carpeta del sitio por el descargado.
5) Si el sitio ya está alojado, subir ese archivo al servidor o repositorio.
6) Actualizar la página.

IMPORTANTE: no hay login ni sincronización en línea.
Para edición segura y publicación desde varios dispositivos hará falta
configurar alojamiento, autenticación y un gestor de contenidos.
