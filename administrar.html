Editor de novedades

Creá, modificá o eliminá noticias y comunicados, sin editar HTML.

Importante: este editor funciona de forma local y no tiene acceso protegido. Los cambios no se publican automáticamente. Para publicarlos, descargá el archivo contenido.js y reemplazá el anterior en la carpeta del sitio (y luego subí la actualización al alojamiento web). No lo uses para información privada de alumnos.
